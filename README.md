# Game Save Backup Tool

Game Save Backup Tool (GSBT) backs up and restores game saves on Windows. This repository hosts its Windows x64 downloads. Visit the [preview website](https://preview.gsbt.dev/) or email [support@gsbt.dev](mailto:support@gsbt.dev).

## Downloads

Get the Windows installer, portable desktop ZIP, or standalone CLI ZIP from [GitHub Releases](https://github.com/Xeworth/gsbt-releases/releases). This is a pre-alpha. Try the backup and restore workflow with a disposable save first. Windows may show a SmartScreen prompt for the unsigned installer.

Each release includes SHA-256 checksums and third-party notices. The [CLI manual](docs/AGENTS.md) lists commands and examples.
